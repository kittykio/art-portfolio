## 1. Headings & Paragraphs

Markdown supports multiple heading levels:

# H1 Heading

## H2 Heading

### H3 Heading

#### H4 Heading

##### H5 Heading

###### H6 Heading

Paragraphs can contain **bold**, _italic_, ~~strikethrough~~, `inline code`, and [links](https://example.com).
